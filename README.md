# Music Secret Science

**Sound, Music & the Living Body**

*Music’s Magic — And the Secrets We Haven’t Unlocked*

A cinematic, shareable resource exploring the deep relationship between music, vibration, and the living body. Sixteen ordered graphics designed for easy sharing, plus a full article page.

**Live site (after Vercel deploy):** https://musicsecretscience.vercel.app

## Structure

- `index.html` — Homepage with 16 numbered image cards
- `article.html` — Full article (readable, shareable, printable)
- `images/` — Place the series graphics here as:
  - `mss-01.png` … `mss-16.png`

## Deploy to Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import the GitHub repo `Caelverum/musicsecretscience`
3. Framework Preset → **Other**
4. Project Name → `musicsecretscience`
5. Deploy

Once images are uploaded to the `images` folder the full series will appear.

## Features

- 16 numbered cards in exact order
- One-click share (X / Facebook / LinkedIn / Email / Copy / Download)
- Tap image → full-size in new tab
- Sticky header + mobile hamburger menu
- Strong SEO, Open Graph & Twitter cards
- Print / PDF friendly article page
